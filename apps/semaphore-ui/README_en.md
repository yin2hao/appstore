## Introduction

[Semaphore UI](https://github.com/semaphoreui/semaphore) provides a web interface for managing and running Ansible, Terraform and OpenTofu automation. Organize repositories, inventories and credentials by project, and run Bash scripts.

## Features

- Task execution: Run reusable task templates on demand or on a schedule.
- Project management: Manage repositories, inventories, variables and access credentials.
- Execution history: View task output and status, and receive failure notifications.
- Access control: Manage user access to projects and deployment operations.
