## Introduction

**SillyTavern** is an LLM frontend for power users that helps manage characters, chats, prompts, extensions, and connections to multiple model APIs.

## Features

- **Multi-model Frontend**: Provides a unified web interface for connecting to and using multiple LLM backends and APIs.
- **Character and Chat Management**: Persists character cards, chat history, world info, presets, and user data.
- **Plugins and Extensions**: Supports plugins and third-party extensions to enhance the frontend.
